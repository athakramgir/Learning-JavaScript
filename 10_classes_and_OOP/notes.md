# JavaScript and Classes

## OOPs in JavaScript
- It is a programming paradigm which is implemented with the help of objects and classes. 
- Although JavaScript is NOT an object-oriented programming language, it is a prototype-based language, which provides the syntax for OOPs internally. 
- JavaScript's OOP is prototype-based, unlike languages such as Java or C++ which are primarily class-based.
JavaScript's class syntax is essentially a more convenient way of working with the underlying prototype system.
- JavaScript is a multi-paradigm language that supports object-oriented programming. Its object-oriented model is prototype-based, although it provides class syntax for creating objects and implementing inheritance.
